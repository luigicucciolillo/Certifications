### AI Agent Nights

**Provider:** [ProfessionAI](https://profession.ai/)
**Duration:** 3 days (~8 hours)
**Format:** Live online training
**Date:** 7-8-9 July 2026

A practical three-day course focused on designing and developing AI agents using progressively more advanced approaches, from no-code automation to framework-based development and custom multi-agent architectures.

The course covered:

* Building a functional no-code AI agent with **n8n**, including tools, workflows and real-world automations.
* Developing stateful AI agents with **LangGraph**, using execution graphs, conditional branches, controlled loops and guardrails.
* Creating a **multi-agent system from scratch** in Python without relying on external frameworks.
* Implementing peer-to-peer agent communication and shared blackboard architectures.
* Managing agent state, memory, tool usage and execution flow.
* Preventing infinite loops and improving the reliability of agentic workflows.
* Understanding the differences between no-code workflows, agent frameworks and custom agent architectures.

The course provided a practical introduction to the main concepts and technologies used in modern agentic AI systems, including **n8n, LangGraph, Python, ReAct, MCP, tool use, guardrails, memory and multi-agent coordination**.

# First day
## Your First AI Agent with No-Code

During this session, a fully functional AI agent was built with **n8n**, starting from the initial idea and progressing to a complete agentic workflow integrated with real tools and automations.

The course explained how to design and orchestrate an AI agent without writing code, while also exploring the advantages, limitations, and most suitable use cases for no-code solutions.

**Skills acquired:**

* Building an AI agent with n8n
* Designing agentic workflows
* Integrating tools and automations
* Managing the agent’s execution flow
* Understanding the limitations of no-code solutions
* Identifying when a code-based approach is more appropriate

**Trainer:** Samuele Bolotta - Senior AI Trainer at ProfessionAI

# Second day
## Stateful AI Agents with LangGraph

During this session, a stateful AI agent was developed using **LangGraph**, with explicit state management, an execution graph, controlled loops, conditional branches, and guardrails.

The course showed how agent frameworks provide greater control, robustness, and flexibility than basic workflows, making them more suitable for real-world use cases where agents must handle complex execution paths and maintain reliable behaviour.

**Skills acquired:**

* Building a stateful AI agent with LangGraph
* Managing explicit agent state
* Designing graph-based execution flows
* Implementing conditional branches and controlled loops
* Adding guardrails to improve reliability
* Understanding when an agent framework is preferable to a standard workflow
* Designing more robust agents for real-world scenarios

**Trainer:** Giovanni Galatro - Senior AI Engineer at IBM

# Third day
## Multi-Agent Systems from Scratch

During this session, a complete **multi-agent system** was designed and developed from scratch without relying on external frameworks.

The course explored the core mechanisms behind multi-agent architectures, including peer-to-peer mesh communication, shared blackboard patterns, loop-prevention guards, and distributed decision-making emerging from interactions between agents.

**Skills acquired:**

* Designing a multi-agent system without frameworks
* Implementing peer-to-peer agent communication
* Using a shared blackboard architecture
* Coordinating multiple autonomous agents
* Preventing infinite execution loops
* Understanding multi-agent system topologies
* Managing distributed decision-making
* Understanding the mechanisms hidden beneath agent frameworks

**Trainer:** Riccardo Musmeci - Senior AI Engineer at Enel
